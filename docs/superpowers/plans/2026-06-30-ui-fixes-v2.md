# CoolDesk UI Fixes v2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix all reported UI/UX issues across Jobs, Technicians, Dealers, Payments & Brands, Notifications, Sidebar, and System Config to match the Figma reference, with TDD throughout.

**Architecture:** Most changes are pure frontend. Backend changes: (1) Schedule & Assign SQL query fix, (2) new `GET /office/technicians/:id/jobs` endpoint, (3) `installation_charge` column added to `brands` table. All job-lifecycle enforcement is frontend-only — no backend validation added.

**Tech Stack:** Next.js App Router, React, TanStack Query, NestJS, PostgreSQL (Neon), TypeScript, inline styles.

## Global Constraints

- Color palette: `#0A0A0A` (near-black), `#FAFAFA` (near-white), `#F9F9F9` (bg), `#E5E5E5` (border), `#737373` (muted), `#171717` (body text), `#525252` (secondary), `#404040` (tertiary), `#10B981` (green/active), `#EF4444` (red/error), `#F59E0B` (amber). No other colors.
- No Tailwind — all styles are inline `style={{}}` objects.
- Font sizes: large headings `36px` weight `600`; cards `15px` weight `500-600`; labels `13px`; helper `12px`; table headers `11px uppercase weight 600 letterSpacing "0.04em"`.
- Border-radius: cards/panels `12px`, buttons `8px`, pills `9999px`.
- All new API functions go in existing `frontend/src/lib/api/` files (prefer `operations.ts`).
- All new TypeScript types go in `frontend/src/types/operations.ts` unless a domain-specific file exists.
- Backend: use `DatabaseService.query(sql, params)` pattern — no raw `pg` Pool imports.
- `customer_name` is stored directly on `jobs` table — no separate `customers` table.
- `installation_charge` does NOT exist in `brands` yet — a DB migration is required.
- TDD: write failing tests first for any backend service method changes. Backend spec files: `*.service.spec.ts`. Frontend: Jest/RTL for testable pure-function logic.
- Commit after each task with a descriptive message.

async getTechnicianJobs(
  technicianId: string,
  ctx: RequestContext,
): Promise<Record<string, unknown>[]> {
  const result = await this.db.query(
    `
    SELECT
      j.id,
      j.customer_name,
      j.type,
      j.status,
      j.created_at,
      COALESCE(SUM(p.amount) FILTER (WHERE p.status = 'collected'), 0) AS amount_collected,
      ROUND(AVG(r.rating)::numeric, 1) AS avg_rating
    FROM jobs j
    LEFT JOIN payments p
      ON p.job_id = j.id
      AND p.organization_id = j.organization_id
      AND p.is_deleted = FALSE
    LEFT JOIN customer_reviews r
      ON r.job_id = j.id
      AND r.organization_id = j.organization_id
    WHERE j.organization_id = $1
      AND j.technician_id = $2
      AND j.is_deleted = FALSE
    GROUP BY j.id, j.customer_name, j.type, j.status, j.created_at
    ORDER BY j.created_at DESC
    LIMIT 50
    `,
    [ctx.organizationId, technicianId],
  );

  return result.rows as Record<string, unknown>[];
}
